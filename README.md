A program that writes one one-line summary of the week for make.fun to
`/output/entry.txt`, for the make.fun competition
[Your Week in One Line](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced).

## Run it

```sh
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 73 characters, inside the 1 to 100 gate, and
exactly one line.

## The entry

```
120 entries in, zero wins, three builds broke, still queued the next one.
```
